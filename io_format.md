# IO-format

Convienient format for Steiner Tree Problem on undirected Graph:

```text
N 
M
u_i v_i w_i (M lines)
k = |S|
S_1 
S_2 
... 
S_k
```

N nodes, M edges.

There's an edge (u_i, v_i) with weight w_i

S is the set of terminal

[PACE or DIMACS testset](https://steinlib.zib.de/format.php) will be re-format-ed correspondingly
